# FinanceIQ

FinanceIQ — персональная веб-платформа для учета, анализа и прогнозирования финансов. Проект помогает понимать структуру доходов и расходов, отслеживать денежные потоки и прогнозировать расчетный остаток по проведенным операциям на ближайшие 30 дней.

Разрабатывается как практический инструмент для личных финансов и портфолио-проект с акцентом на точность расчетов, безопасность пользовательских данных и поддерживаемую архитектуру.

## Текущий статус

Проект находится на этапе проектирования MVP. Подготовлены продуктовая спецификация, доменная модель и проект схемы PostgreSQL; часть решений согласована, схема в целом пока не утверждена. Реализация приложения и окружения запуска ещё не начата.

## Планируемые возможности MVP

- Регистрация и авторизация с изоляцией данных пользователей.
- Управление финансовыми счетами, просмотр и фильтрация транзакций.
- Импорт ручного журнала Money Manager XLSX с проверкой, предварительным просмотром, выявлением дублей и подтверждением.
- Автоматическая категоризация по правилам и ручное изменение категорий.
- Дашборд доходов, расходов, денежных потоков и динамики по периодам.
- Базовый прогноз расчетного остатка на 30 дней при достаточной истории и подтвержденных остатках счетов, с указанием ограничений расчета.

MVP рассчитан на одну валюту — RUB — и один профиль импорта: `money_manager_xlsx_v1` из ручного журнала Money Manager (согласован 2026-10-30 вместо банковского CSV). Задачи проектирования 0.7–0.12 завершены: профиль, идентичность книги, fingerprint, явное разрешение повторов, блокирующие ошибки и допустимые действия, лимиты ресурсов, срок preview, хранение, жизненный цикл фактов и детали категорий согласованы. Исходный журнал ведется в Money Manager; FinanceIQ допускает исправление классификации/связей, контролируемую отмену всей книги и архив счета с сохранением истории. Приняты нормализация текста, приоритеты правил, десять персональных начальных категорий без правил и архивирование категорий. В 0.13 модель/схема актуализированы: подготовлены попытки/наблюдения/отмены, доказательства решений и матрица 36 инвариантов с 12 дополнительными сценариями. Технический пакет 0.13 ожидает согласования. В 0.14 подготовлен проект архитектуры: семь модулей, структура monorepo, сервисные транзакции, взаимодействие и механизмы ресурсов/очистки. Предложения 0.14 также ожидают согласования; переход к этапу 1 не утвержден. Приложение, отмена импорта, очистка и резервное копирование еще не реализованы.

## Выбранный стек

- **Frontend:** Next.js (App Router), TypeScript, Tailwind CSS, shadcn/ui, TanStack Query, React Hook Form, Zod, Recharts.
- **Backend:** Python, FastAPI, SQLAlchemy 2, Alembic, Pydantic; Pandas для аналитики.
- **База данных:** PostgreSQL; денежные расчеты — Python Decimal и PostgreSQL NUMERIC.
- **Инфраструктура и тестирование:** Docker Compose, GitHub Actions, pytest, Vitest, Playwright.

Архитектура — монорепозиторий с модульным монолитом на backend и REST API с префиксом `/api/v1`.
