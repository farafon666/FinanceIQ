## Порядок работы

- Этапы выполняются в указанном порядке с учетом зависимостей. Один пункт — отдельная задача с проверяемым результатом; если изменение перестает быть небольшим, его нужно дополнительно разбить перед реализацией.
- Перед каждым этапом согласуются его объем и критерии приемки. После выполнения критериев — контрольная точка: переход к следующему этапу требует отдельного согласования пользователя.
- Нерешенный вопрос блокирует зависимые задачи. Рекомендации из `DECISIONS.md` не становятся значениями по умолчанию.
- Пункт отмечается выполненным только после реализации и применимых проверок. Наличие описания или тестового сценария в документации не означает готовность кода.
- Изменения правил, модели данных и API сопровождаются обновлением соответствующих документов в том же изменении. Этот план хранит порядок работы, а сами правила остаются в профильных документах.
- Тесты значимой логики и изоляции добавляются вместе с модулем. Финальный этап проверяет их совместную работу.

## Общие условия завершения задачи

Каждый отмеченный пункт должен иметь проверяемый результат, применимые тесты и актуальную документацию. При изменении API обновляются OpenAPI и сгенерированные frontend-контракты; при изменении данных — миграции и описание схемы. Проверки выполняются на синтетических данных; реальные выписки, секреты и credentials в Git не добавляются.

Сценарии `T-01`–`T-33` и инварианты `C-01`–`C-11` служат исходным перечнем рисков. Их условные ожидания уточняются после согласования соответствующих `D-xx`, а не превращаются в утвержденные правила через тесты.

## За пределами этого плана

Банковские API, банковский CSV-импорт, PDF-импорт, несколько форматов импорта, мультивалютность и конвертация, ML-категоризация, Prophet и сравнение моделей, полноценные what-if сценарии, подписки/биллинг, Redis/Celery и микросервисы не входят в MVP. Расписания платежей также пока не добавляются.

Публикация кода во внешних сервисах, деплой и операции с production требуют отдельного задания и разрешения; завершение этого плана их не запускает.
